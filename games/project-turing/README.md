# Project Turing

> **AI Among Us**: 5명의 사람 중 숨어있는 AI를 찾아라!

---

## 🎯 게임 개요

**Project Turing**은 튜링 테스트에서 영감을 받은 5인 협동 추리 게임입니다.

5명의 참가자가 모이면, 시스템이 비밀리에 AI 플레이어 1명을 추가합니다. 매 턴마다 주어지는 질문에 모두가 답변하고, 참가자들은 "누가 AI인지" 추론하여 투표합니다. **최소 턴으로 AI를 찾아낸 팀이 우승**합니다.

---

## 🎮 게임 룰

### 기본 구성
- **참가자**: 5명 (네오랩컨버전스 임직원)
- **AI 플레이어**: 1명 (Gemini AI)
- **총 인원**: 6명 (5명 참가자 + 1명 AI)

### 게임 흐름

```
1. [매칭] 5명 참가자 대기실 → 매칭 완료
    ↓
2. [AI 투입] 시스템이 비밀리에 AI 1명 추가 (참가자는 누가 AI인지 모름)
    ↓
3. [난이도 선택] 참가자들이 협의하여 난이도 선택 (Easy/Normal/Hard)
    ↓
4. [게임 시작] 턴 1 시작
    ↓
5. [질문 제시] 주제 질문 표시 (예: "최근에 본 영화는?")
    ↓
6. [동시 답변] 모든 참가자 + AI가 60초 안에 답변 작성
    ↓
7. [답변 공개] 타이머 종료 후 모든 답변 동시 공개 (익명, 랜덤 순서)
    ↓
8. [토론 시간] 30초간 채팅으로 의견 교환 (선택사항)
    ↓
9. [투표] 5명의 참가자가 "누가 AI인가?" 투표 (자신 제외)
    ↓
10. [결과 확인]
    ├─ AI 맞음 → 게임 종료 ✅ (성공, 턴 수 기록)
    ├─ AI 아님 → 다음 턴 진행 (최대 5턴)
    └─ 5턴 초과 → AI 승리 ❌ (실패)
    ↓
11. [리더보드] 최소 턴으로 AI를 찾은 팀 순위
```

## 🎲 난이도 시스템

| 난이도 | AI 답변 전략 | AI 답변 타이밍 | 제한 시간 | 최대 턴 |
|--------|-------------|---------------|----------|---------|
| **Easy** | 로봇같은 답변 (완벽한 문법, 감정 X) | 타인 답변 참고 X | 60초 | 5턴 |
| **Normal** | 자연스러운 답변 | 타인 답변 참고 X | 45초 | 5턴 |
| **Hard** | 타인 답변 패턴 모방 | 4명(80%) 제출 후 분석 | 30초 | 5턴 |

**공통사항**: 모든 난이도에서 답변 공개는 익명 + 랜덤 순서

### 난이도별 특징

#### Easy
- **AI 핸디캡**: 로봇같은 답변 스타일로 쉽게 식별 가능
- **답변 예시**: "영화 관람 했습니다. 제목은 인터스텔라입니다."
- **적합 대상**: 튜링 게임 처음 하는 사람들

#### Normal
- **균형잡힌 난이도**: AI가 자연스럽게 답변하지만 타인 모방은 안 함
- **답변 예시**: "인터스텔라 봤어요! 재밌더라고요"
- **적합 대상**: 표준 난이도

#### Hard
- **AI 유리**: 4명 제출 후 답변 길이/스타일 분석하여 평균에 맞춤
- **짧은 시간**: 30초 안에 답변 → 깊은 고민 어려움
- **답변 예시**: "저도 오펜하이머 봤는데 진짜 인상 깊었어요" (타인 스타일 모방)
- **적합 대상**: 고수들

## 💡 전략 가이드

### AI를 찾는 팁

1. **답변 패턴 분석**
   - 너무 완벽한 문법
   - 개인적 감정 표현 부족
   - 구체적 경험 디테일 부족

2. **사내 문화 질문 활용**
   - "점심 메뉴 추천은?"
   - "우리 회사 최근 소식은?"
   - AI는 사내 정보를 모를 수 있음

3. **토론 시간 활용**
   - 의심스러운 답변에 대해 의견 교환
   - ⚠️ 주의: AI는 토론 시간에 채팅 참여 불가

4. **이전 턴 일관성 체크**
   - 턴마다 답변 스타일이 바뀌는 사람 의심

### AI가 이기는 전략 (AI 관점)

1. **짧고 자연스럽게**
   - 긴 설명보다 짧은 답변
   - "저는 ~했어요" 대신 "~했어요"

2. **감정 표현 추가**
   - "너무 재밌었어요!", "진짜 좋더라고요!"

3. **타인 모방**
   - Hard 모드에서는 다른 사람 답변 길이 평균 따라가기

4. **구체성 균형**
   - 너무 구체적 → 의심
   - 너무 추상적 → 의심
   - 적당한 중간 선택

## 📊 점수 시스템

### 점수 계산 (골프 스코어 방식)

```
점수 = (찾은 턴 수 / 난이도 배율) * 1000 + (경과 시간 / 1000)
```

- **낮은 점수 = 높은 순위**
- **난이도 배율**:
  - Easy: 1.0
  - Normal: 1.3 (30% 보정)
  - Hard: 1.6 (60% 보정)

### 예시

| 난이도 | 턴 수 | 경과 시간 | 점수 계산 | 최종 점수 |
|--------|-------|----------|----------|-----------|
| Easy | 2턴 | 150초 | (2/1.0)*1000 + 150 | **2,150점** |
| Normal | 2턴 | 120초 | (2/1.3)*1000 + 120 | **1,659점** ⭐ (더 높은 순위) |
| Hard | 2턴 | 90초 | (2/1.6)*1000 + 90 | **1,340점** ⭐⭐ (최고 순위) |

**어려운 난이도일수록 같은 턴 수에도 더 높은 순위!**

## 🏆 리더보드

### 기록 항목
- 팀 이름 (자동 생성: "2025-01-15 19:30 팀")
- 난이도
- 찾은 턴 수
- 총 경과 시간
- 최종 점수
- 각 턴별 질문 & 답변 히스토리
- AI의 답변들

### 순위 기준
1. **1차**: 최종 점수 (낮을수록 좋음)
2. **2차**: 찾은 턴 수 (적을수록 좋음)
3. **3차**: 경과 시간 (짧을수록 좋음)
